04 / Accuracy lab

Baseline coverage 0/60. New pass 26/60.

The deliberately selected sample contains one app from each category and six fields per app: authentication, credential access, API surface, official MCP, Composio toolkit, and build verdict. The preserved first pass abstained on 60/60 claims; it answered 0/60. Accuracy among answered claims is 0/0, undefined. The new pass answered 26/60. On those 26 answers, independent AI-assisted review found 19 correct and 7 partial. With partial answers worth half, the weighted score is 22.5/26 (86.5%); strict full-credit accuracy is 19/26 (73.1%). This is a selected ten-category sample, not a population estimate. There is no baseline accuracy comparison and no random holdout.
